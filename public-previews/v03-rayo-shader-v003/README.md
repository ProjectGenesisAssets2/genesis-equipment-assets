# Project Genesis · Canal Rayo · Prueba V003

**Candidato experimental de VFX para PC — pendiente de evaluación del usuario.**

Prueba basada en el **GLB V03 original** (SHA-256 `e2228f078b2572768416c48c0e63c2d908f214e2c0625a2ab754c877a099112b`), con hierro V175, shader procedimental sobre una capa de Emissive, `CameraFrame` Bloom HDR y HDRI Poly Haven Studio Small 09 en formato Radiance RGBE (32 bits por píxel de alto rango dinámico).
